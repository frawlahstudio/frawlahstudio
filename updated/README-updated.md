## التحديث 2 — الحفاظ على الأيقونات عند تبديل اللغة

### الملف

```
updated/updated-lang-icons.js
```

### المشكلة التي يحلها

دالة `setLanguage()` في `script.js` تستبدل `textContent` لكل عنصر يحمل
`data-ar` / `data-en`. العناصر التي تحتوي أيضاً على أيقونة تفقد الأيقونة عند
أول تحميل وعند كل تبديل لغة:

| العنصر | الأيقونة المفقودة |
|---|---|
| `.hero-buttons .btn-primary` | `fa-clapperboard` |
| `.hero-buttons .btn-outline` | `fa-calendar-days` |
| `.dropbtn` (قائمة البراندات) | `fa-chevron-down` |

### الحل

يعيد السكربت إدراج الأيقونات الأصلية بعد كل تغيير لغة:

- يعمل بعد `script.js` مباشرة.
- لا يكرر الأيقونة إذا كانت موجودة (idempotent).
- يعيد التطبيق عند الضغط على زر اللغة وعبر `MutationObserver` على تغيّر
  `dir` / `lang` في وسم `<html>`.

## التحديث 3 — إصلاح قائمة «البراندات» على الهواتف واللمس

### التاريخ

**2026-11-12**

### الملفات

```
updated/updated-brands-dropdown.js
updated/updated-brands-dropdown.css
```

### المشكلة

عند الضغط على زر «البراندات» في الهاتف، لا تظهر القائمة المنسدلة ويبدو الزر
كأنه لا يستجيب للمس.

### السبب الحقيقي

كان `script.js` يربط مستمع `click` بكل روابط `.nav-list a` — بما فيها زر
`.dropbtn`. عند لمس الزر كان مستمع القائمة الجوالة يغلق القائمة كاملة وتنزلق
خارج الشاشة **قبل** أن يظهر تأثير فتح القائمة المنسدلة. أي أن القائمة كانت
تُفتح فعلياً لكن داخل قائمة جوالة اختفت بالفعل.

أسباب مساعدة:

- الاعتماد على `click` فقط دون `touch-action: manipulation`.
- قاعدة `max-height: 200px` القديمة كانت تقص روابط البراندات.
- بين `769px` و`1024px` كانت القائمة تتمدد داخل الهيدر بخلفية شفافة فوق
  السلايدر بدلاً من أن تطفو كقائمة منسدلة.

### الحل

- معالجة اللمس في مرحلة **capture** عبر `touchstart` / `touchmove` /
  `touchend` مع `preventDefault()` و`stopPropagation()`، فلا تُغلق قائمة
  الجوال عند لمس زر البراندات.
- معالجة `click` في مرحلة **capture** مع إزالة التكرار بعد اللمس، لتغطية
  الماوس ولوحة المفاتيح والمتصفحات التي لا تدعم أحداث اللمس.
- `touch-action: manipulation` على زر البراندات وروابط البراندات، مع هدف لمس
  لا يقل عن `44px`.
- طبقات صريحة: الهيدر `1100`، قائمة الجوال `1200`، القائمة المنسدلة المفتوحة
  `1300` — أعلى من السلايدر (`1–3`) وواتساب العائم (`999`) وأقل من الـ
  Lightbox (`2000`).
- قائمة عائمة حقيقية للتابلت `769–1024px`، وقائمة قابلة للتمدد مع تمرير
  داخل قائمة الجوال حتى `60vh` للهواتف.
- إغلاق تلقائي عند اختيار براند أو إغلاق القائمة أو الضغط خارجها أو `Escape`
  أو العودة لسطح المكتب، مع تحديث `aria-expanded`.

### إصلاح إضافي

`max-height` للقائمة المفتوحة أصبح `min(60vh, 480px)` بدلاً من `200px`،
فقائمة الجوال أصبحت قابلة للتمرير ولا تقص أي رابط.

## التحديث 4 — استبدال رابط واتساب بالرابط الرسمي الجديد

### التاريخ

**2026-11-12**

### الملفات

```
updated/updated-whatsapp-config.js
updated/updated-whatsapp-link.js
```

### الرابط الجديد

```
https://wa.me/qr/7OPJFROHEVRGM1
```

### ما تم تنفيذه

- **زر واتساب العائم:** استُبدل الرابط القديم بالرابط الجديد مباشرة في
  `index.updated.html`، مع `target="_blank"` و`rel="noopener noreferrer"`.
- **أيقونات السوشيال ميديا + الفوتر:** أُضيفت أيقونة واتساب إلى
  `.footer-social` بالرابط الجديد، لتصبح أول أيقونة في التذييل.
- **ملف إعدادات مركزي:** `updated/updated-whatsapp-config.js` يحتوي الرابط
  الرسمي، فأي تغيير مستقبلي يتم من سطر واحد.
- **سكربت الاستبدال الشامل:** `updated/updated-whatsapp-link.js` يفحص كل
  روابط واتساب القديمة ويستبدلها، بما فيها:
  - `wa.me`
  - `api.whatsapp.com`
  - `web.whatsapp.com`
  - `chat.whatsapp.com`
  - `whatsapp:`
- يعمل السكربت أيضاً على الروابط التي تُضاف ديناميكياً بعد تحميل الصفحة عبر
  `MutationObserver`، ولا يكرر أيقونة الفوتر.
- رقم الهاتف الظاهر في قسم التواصل **نص وليس رابط واتساب**، لذلك بقي كما هو
  دون تغيير.

### نتيجة البحث في المشروع

| المكان | النتيجة |
|---|---|
| زر واتساب العائم | رابط قديم واحد — تم استبداله |
| أيقونات السوشيال ميديا / الفوتر | لا توجد أيقونة واتساب — تمت إضافتها بالرابط الجديد |
| ملفات الإعدادات | لا توجد ملفات إعدادات — تم إنشاء ملف إعدادات مركزي |
| `script.js` / `style.css` | لا تحتوي أي رابط واتساب |
| `index.html` (الأساسي) | ما زال يحتوي الرابط القديم لأنه لم يُعدَّل حسب قاعدة العمل |

## التطبيق الجاهز — `index.updated.html`

تم إنشاء نسخة كاملة من صفحة الموقع مع التحديثات الأربعة مطبّقة بالفعل:

```
index.updated.html
```

- مطابق تماماً لـ `index.html` مع **سبعة أسطر إضافية فقط** (404 ← 411 سطراً).
- لم يتم تعديل `index.html` نفسه.

### للنشر على GitHub

1. ارفع `index.updated.html` مع مجلد `updated/`.
2. راجع التغييرات.
3. عند الموافقة، استبدل محتوى `index.html` بمحتوى `index.updated.html`
   (أو أعد تسمية الملف إلى `index.html`).

> GitHub Pages يخدم `index.html` فقط، لذلك لا يصبح التحديث مباشراً على الموقع
> حتى تتم خطوة الاستبدال.

### أو التطبيق اليدوي (ستة أسطر برمجية + أيقونة الفوتر)

**داخل `<head>` بعد `category-views.css` مباشرة:**

```html
<link rel="stylesheet" href="updated/updated-mobile-icons.css">
<link rel="stylesheet" href="updated/updated-brands-dropdown.css">
```

**قبل `</body>` بعد `script.js` مباشرة:**

```html
<script src="updated/updated-lang-icons.js" defer></script>
<script src="updated/updated-brands-dropdown.js" defer></script>
<script src="updated/updated-whatsapp-config.js" defer></script>
<script src="updated/updated-whatsapp-link.js" defer></script>
```

> **مهم:** وجود `defer` يضمن تنفيذ السكربتات بعد `script.js` مباشرة، وترتيب
> ملف إعدادات واتساب قبل سكربت الاستبدال مطلوب.
