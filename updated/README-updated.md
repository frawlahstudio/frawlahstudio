## التحديث 1 — تصغير الأيقونات على الهواتف

### الملف

```
updated/updated-mobile-icons.css
```

### ماذا يفعل؟

يطبّق القواعد **فقط** عند عرض الموقع بعرض أقل من `768px`:

- تصغير أيقونات:
  - زر القائمة واللغة في الهيدر
  - أيقونات الإحصائيات
  - نجوم التقييمات
  - أيقونات التواصل (الموقع، البريد، الهاتف)
  - أزرار الصوت والتكبير على الفيديوهات
  - زر إغلاق الـ Lightbox
  - أيقونة واتساب العائمة
  - أيقونات السوشيال في الفوتر
- إعادة ضبط المسافات (padding / margin / gap) حول الأيقونات لتبدو متناسقة.
- نقطة تحسين إضافية للشاشات الأصغر من `480px`.
- لا يوجد أي تأثير على تصميم الديسكتوب.

## التحديث 2 — الحفاظ على الأيقونات عند تبديل اللغة

### الملف

```
updated/updated-lang-icons.js
```

### المشكلة التي يحلها

دالة `setLanguage()` في `script.js` تستبدل `textContent` لكل عنصر يحمل
`data-ar` / `data-en`. العناصر التي تحتوي أيضاً على أيقونة تفقد الأيقونة عند
أول تحميل وعند كل تبديل لغة:

| العنصر | الأيقونة المفقودة |
|---|---|
| `.hero-buttons .btn-primary` | `fa-clapperboard` |
| `.hero-buttons .btn-outline` | `fa-calendar-days` |
| `.dropbtn` (قائمة البراندات) | `fa-chevron-down` |

### الحل

يعيد السكربت إدراج الأيقونات الأصلية بعد كل تغيير لغة:

- يعمل بعد `script.js` مباشرة.
- لا يكرر الأيقونة إذا كانت موجودة (idempotent).
- يعيد التطبيق عند الضغط على زر اللغة وعبر `MutationObserver` على تغيّر
  `dir` / `lang` في وسم `<html>`.

## التطبيق الجاهز — `index.updated.html`

تم إنشاء نسخة كاملة من صفحة الموقع مع التحديثين مطبّقين بالفعل:

```
index.updated.html
```

- مطابق تماماً لـ `index.html` مع **سطرين إضافيين فقط** (404 ← 406 سطراً).
- لم يتم تعديل `index.html` نفسه.

### للنشر على GitHub

1. ارفع `index.updated.html` مع مجلد `updated/`.
2. راجع التغييرات.
3. عند الموافقة، استبدل محتوى `index.html` بمحتوى `index.updated.html`
   (أو أعد تسمية الملف إلى `index.html`).

> GitHub Pages يخدم `index.html` فقط، لذلك لا يصبح التحديث مباشراً على الموقع
> حتى تتم خطوة الاستبدال.

### أو التطبيق اليدوي (سطران)

**داخل `<head>` بعد `category-views.css` مباشرة:**

```html
<link rel="stylesheet" href="updated/updated-mobile-icons.css">
```

**قبل `</body>` بعد `script.js` مباشرة:**

```html
<script src="updated/updated-lang-icons.js" defer></script>
```

> **مهم:** وجود `defer` يضمن تنفيذ السكربت بعد `script.js` مباشرة، لأن ترتيب
> التنفيذ يعتمد على انتهاء `setLanguage()` من عملها.

## التراجع

- لحذف تحديث الأيقونات: احذف سطر الـ `<link>`.
- لإلغاء إصلاح الأيقونات: احذف سطر الـ `<script>`.

لا توجد أي تغييرات أخرى، لذا التراجع لا يترك آثاراً.

---

## قاعدة العمل من الآن فصاعداً

كل تعديل أو ميزة جديدة تُسلَّم في ملف مستقل يحمل كلمة `updated` في اسمه
(مثل `updated-style.css` أو `index.updated.html` أو داخل مجلد `updated/`)،
ولا يتم تعديل الملفات الأساسية مباشرة، حتى تتم المراجعة والرفع بشكل مستقل.
